# 桂林4天漫游攻略（单人 · 国庆版）

一份**纯静态、离线可用**的桂林旅游攻略项目：4天行程、真实道路轨迹导览地图、通勤费用估算，含**正常方案**与**雨天备案**双方案切换。

- **出行人**：单人，住临桂区「在水一方休闲街」（世纪东路大圆盘附近）
- **出行日期**：2026年国庆（10/2-10/6）
- **线上访问**（GitHub Pages）：https://liconyu.github.io/guilin-trip/

## 文件清单

| 文件 | 说明 |
|---|---|
| `index.html` | **离线导览地图**（核心交付物）：SVG手绘地图 + 真实道路轨迹 + 双方案切换 + 逐时刻时间线 + 费用表 |
| `guide.html` | 图文攻略：四天详细时间线、费用汇总、美食清单、导航坐标表 |
| `guide.pdf` | 攻略PDF版（打印/转发用） |

三个文件互相独立，任何一个单独打开都完整可用，**无需联网、无外部依赖、无构建步骤**。

## index.html 功能说明

- **方案切换**：顶部日签栏下方「出行方案」下拉框（`#planSel`），可在 **正常方案（原计划）** 与 **备案1·雨天版** 之间切换；切换后地图路线、景点标记、图例、行程时间线、费用表全联动
- **日签筛选**：全部 / Day1-4，只显示当天路线与行程
- **景点卡片**：点击地图标记弹出底部卡片（说明+打车时间+坐标一键复制）
- **地图操作**：按钮缩放 / 拖拽平移 / 复位
- **离线**：所有路线几何数据内嵌在文件中（`ROUTE_GEO`、`ROUTE_B`），无任何网络请求

## 行程概要

### 正常方案
| 天 | 内容 |
|---|---|
| D1 | 临桂慢生活 + 会仙湿地（船游2.5h） |
| D2 | 老城扫街（东西巷/王城/滨江路）+ 穿山日落 + 文化宫夜宵 |
| D3 | 金山广场早茶 + 罗汉山日落机位 + 文化宫 |
| D4 | 会仙玻璃田（清晨镜面）+ 会仙镇午餐 + 返程 |

### 备案1·雨天版（针对10/2-10/4降雨）
| 天 | 内容 | 思路 |
|---|---|---|
| D1 | 桂林博物馆（免费，凭身份证，9:00-17:00，16:30停止入馆） | 中午强降雨时段躲室内 |
| D2 | 老城骑楼逛吃线（东西巷→王城→文化宫） | 全程有遮挡 |
| D3 | 上午休整，15:00决策点：雨停则罗汉山日落 | 灵活窗口 |
| D4 | 晴日窗口：玻璃田+湿地一日连打（包车300-350元） | 山水集中到晴天 |

费用：正常方案≈145km≈377元起；备案≈156km≈395元起（国庆上浮10-20%）。

## 技术要点（供后续修改者/工具参考）

- **单文件HTML**：CSS/JS/SVG全部内联，UTF-8，无框架
- **地图坐标系**：经纬度→SVG投影公式
  - `x = 21 + (lon - 110.2073) * 763.6`
  - `y = 35.5 + (25.2466 - lat) * 843.9`
  -（763.6 = 843.9 × cos(25.2°)，保证横纵比例一致）
- **viewBox**：`-12 0 112 194.1`（向西扩到-12以容纳桂林博物馆，`MAP_W=112`；宽高比计算统一用 `MAP_H/MAP_W`）
- **路线数据**：`ROUTE_GEO`（正常方案7段）+ `ROUTE_B`（备案4段：bm博物馆/ot东西巷/ret返程/zs会仙镇→湿地），来源为OSRM真实路网（FOSSGIS镜像 routing.openstreetmap.de）
- **切换机制**：元素带 `data-plan` 属性（normal/backup），`planOK()` 过滤 + `renderRoutes()` 全量重建 + `applyPlan()` 切换行程/费用div显隐与图例文字（`LG` 对象）
- **景点数据**：`SPOTS_GEO`（真实坐标）、`SPOTS_B`（博物馆）、`COORDS`（经纬度原值，供复制）

## 设计原则

- **避峰**：不去象鼻山、两江四湖游船、阳朔西街等国庆爆满点
- **交通**：临桂↔市区/会仙一律打车或包车（里程与费用按OSM路网真实道路估算）
- **日落机位**：穿山、罗汉山，日落约18:15-18:30，提前40分钟到位
- **天气策略**：晴天走正常方案，雨天切备案1（室内逛吃优先，山水集中到晴日）
