Day 1临桂慢生活 + 会仙湿地›
  • 12:00到「在水一方休闲街」办入住、放行李
  • 13:00楼下嗦粉当午餐（约40分钟）
  • 13:50出门口打车 → 会仙湿地睦洞七星村（车程约38分钟）
  • 14:30开始逛湿地，约2.5小时：小木船穿梭峰林倒影40-60分钟（船票现场买），沿岸栈道拍照
  • 17:10出园，门口叫车返程（车程约38分钟）
  • 18:00回临桂世纪东路逛街、吃晚饭，晚上自由安排
🚕 临桂 ↔ 湿地 39.7km，约38分钟/程（原路返回）· 单程打车≈96元 · 下午顺光适合上船
Day 2老城扫街 + 穿山落日›
  • 09:40楼下打车 → 东西巷（临桂出发约30分钟）
  • 10:10东西巷 + 正阳步行街扫街，约80分钟（上午人少好拍照）
  • 11:30步行约300米 → 靖江王城外围城墙漫步，约45分钟（登独秀峰要门票且国庆排队，不建议）
  • 12:20步行/短打车去嗦粉：胜利米粉（文明路店）或石记米粉（解放西路店）
  • 12:30午餐 + 歇脚，约1小时
  • 13:30滨江路沿漓江慢走、逍遥楼一带拍照，约2小时（走累了随时打车）
  • 15:40打车 → 穿山公园（3.7km，约10分钟）
  • 16:00穿山公园约2.5小时：步道上山 + 占机位；17:45前务必到位等日落（18:15-18:30）
  • 19:00打车 → 文化宫美食街（3.6km，约10分钟）
  • 19:10晚餐 + 夜宵，烧烤米粉田螺管够
🚶 东西巷→王城 约300m步行 · 🚕 王城→穿山 3.7km · 🚕 穿山→文化宫 3.6km
Day 3罗汉山落日 + 市区烟火›
  • 09:30金山广场早茶，慢悠悠吃到约11:00（今天上午睡到自然醒也行）
  • 11:00回住处午休 / 临桂逛街（躲正午暴晒）
  • 15:30打车 → 罗汉山（将军路橡胶机械厂旁，11.3km约15分钟）
  • 15:45开始登顶，台阶路约15分钟（别走野路）
  • 16:00山顶占机位：等日落18:15-18:30，拍高铁穿晚霞；备好水和零食
  • 18:45下山（约15分钟）
  • 19:05打车 → 文化宫（7.8km，约15分钟）
  • 19:20夜宵：烧烤 + 米粉
  • 21:15打车回临桂休息（约9km，20-30分钟）
🚕 临桂→罗汉山 11.3km≈30元 · 🚕 罗汉山→文化宫 7.8km≈22元 · 🚕 回临桂约9km≈26元
Day 4会仙玻璃田 + 返程›
  • 06:30起床出发（镜面倒影在清晨；建议提前一晚约好包车，07:00楼下等）
  • 07:00出发 → 沐宦头村玻璃田（35.7km，约31-40分钟）
  • 07:40玻璃田约3小时：登龙头山30-40分钟俯瞰全景，田间栈道拍照
  • 10:40叫车 → 会仙镇（2.7km，约10分钟）
  • 11:00镇上闲逛1小时
  • 12:00午餐：农家菜，招牌会仙板鸭
  • 13:30返程（包车直接送站；打车约33km≈80元）
🚕 临桂→玻璃田 35.7km≈86元 · 🚕 玻璃田→会仙镇 2.7km≈11元 · 💡 包车半日约200-260元更省心
Day 1雨天版 · 博物馆躲雨线›
  • 12:00到「在水一方休闲街」办入住、放行李
  • 13:00楼下嗦粉当午餐
  • 13:40打车 → 桂林博物馆·一院两馆（5.6km，约6分钟）
  • 14:00逛馆约2.5小时：12个展厅（明代梅瓶、桂林抗战文化、广西民族风情），全程室内；每日10:00/15:00有免费讲解
  • 16:40出馆，隔壁桂林图书馆/中央公园连廊走一圈（有顶，淋不到）
  • 17:30打车回世纪东路吃晚饭，晚上休闲街逛街
🚕 临桂 ↔ 博物馆 5.6km，约6分/程（≈13元）· 凭身份证免费入馆 · 周一闭馆（法定节假日一般正常开放）
Day 2雨天版 · 老城骑楼逛吃›
  • 09:40楼下打车 → 东西巷（14.1km，约14分钟）
  • 10:00东西巷 + 正阳步行街骑楼下扫街，约90分钟（连廊可躲雨）
  • 11:30雨小顺路绕靖江王城外围一圈（雨大跳过）
  • 12:10午餐：石记米粉或胜利米粉，饭后歇1小时
  • 14:00步行/短打车 → 文化宫美食街：糖水+小吃当下午茶
  • 15:30就近商场/书店歇脚，避开最大雨势
  • 18:00打车回临桂（13.3km，约14分钟），晚饭后休息
🚕 临桂→东西巷 14.1km·≈37元 · 🚶 东西巷→文化宫 约1.2km有骑楼 · 🚕 文化宫→临桂 13.3km·≈35元
Day 3雨天版 · 上午休整 + 傍晚赌日落›
  • 09:30金山广场早茶（雨小步行去，雨大短打车），慢悠悠吃到约11:00
  • 11:00回住处午休，刷雷达图等雨停（转机在下午）
  • 15:00决策点：雨停/转小雨 → 15:30打车罗汉山；仍中雨 → 改逛临桂商场+金山夜市，把山水留给明天
  • 15:45罗汉山登顶约15分钟（走台阶路，雨后湿滑慢点走）
  • 16:00山顶等雨后云海+晚霞：日落18:15-18:30，雨后通透出片概率反而更高
  • 19:05打车 → 文化宫夜宵（7.8km，约10分钟）
  • 21:15打车回临桂（13.3km，约14分钟）
🚕 临桂→罗汉山 11.3km≈30元 · 🚕 罗汉山→文化宫 7.8km≈22元 · 🚕 回临桂 13.3km≈35元 · 若雨未停改逛吃，这三段≈87元省下

避坑提醒

  • 国庆热门点别去：象鼻山、两江四湖游船、阳朔西街、漓江杨堤-兴坪竹筏

  • 天气决定出片，阴雨天改逛吃
  • 临桂往返市区建议打车，公交慢且挤
  • 罗汉山、龙头山别走野路，走有台阶的路
